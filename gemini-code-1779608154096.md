# ⚛️ Smart Physics Calculator

Aplikasi web interaktif berbasis Python yang dirancang untuk membantu mahasiswa dan pelajar menyelesaikan persoalan fisika dasar. Aplikasi ini tidak hanya memberikan hasil akhir, tetapi juga menyertakan **langkah pengerjaan step-by-step**, penjelasan rumus, dan kuis interaktif.

## 🚀 Fitur Utama

1. **Beranda:** Pengenalan materi dan visualisasi topik fisika.
2. **Cheat Sheet Rumus:** Ringkasan tabel Satuan Internasional (SI) dan konstanta fisika penting.
3. **Kalkulator Pintar:** Menghitung otomatis beserta langkah penyelesaian untuk:
   - Kerapatan (Massa Jenis)
   - Analisis Nilai Galat (Error)
   - Viskositas (Hukum Stokes)
   - Pembacaan Jangka Sorong
   - Sudut Reposisi (Angle of Repose)
   - Koefisien Muai Panjang
4. **Auto Unit Converter:** Konversi otomatis antar satuan besaran fisika.
5. **Kuis Fisika Dasar:** Fitur latihan soal (Pilihan Ganda & Isian) tingkat kuliah dilengkapi pembahasan otomatis.
